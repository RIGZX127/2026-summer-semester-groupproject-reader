# Mercury UI 对话框与 Reader 体验改进设计

## 范围

以 `2026-summer-semester-groupproject-reader-main (8).zip` 为唯一代码基线。只修改 `app/styles.py`、`ui/`、`tests/test_ui/` 以及里程碑要求的 `AGENTS.md` 状态，不修改 Core、Store 或业务协议。

## 设计

### 标签管理

- 保留 FlowLayout 标签布局，去除当前标签区过重的深色块视觉。
- 标签区域根据实际内容高度调整；仅当内容超过预设最大高度时显示垂直滚动条。
- 标签加减图标保持小尺寸，按钮点击目标扩大到至少 36×36，并保留 Tooltip 与 accessibleName。

### 导出预览

- 预览框使用主题语义 surface、text、border 角色，不在组件内新增颜色。
- 浅色和深色主题下均显示可读正文；空预览继续显示明确占位文本。

### AI 未配置反馈

- Reader 提供统一、可关闭的“尚未配置 AI 服务”横幅。
- 摘要、翻译和标签入口复用该反馈；横幅提供“打开设置”入口并发出 UI 意图信号，不直接读取或写入 Provider。

### 摘要与笔记

- 底部区域默认显示紧凑标签栏。
- 用户激活摘要或笔记时展开对应内容；折叠时保留当前标签。
- 进入专注模式前记录展开状态与高度并自动折叠；退出时恢复原状态。

### 设置与用量

- 缩短设置窗口默认高度，Provider 和 Agent 表单从面板顶部紧凑排列。
- 用量页使用主题语义背景；无数据时显示“暂无调用记录”空状态。

### 点击目标与已读状态

- 工具栏、侧栏、筛选按钮的最小点击目标统一为 36×36。
- 已读文章只使用语义 muted text 变灰；字重与未读一致，不增加未读圆点。
- Tooltip 和 accessibleName 明确文章已读状态。

## 测试

使用 pytest-qt 先写失败测试，覆盖：

- AI 横幅、关闭和设置入口；
- 摘要/笔记展开折叠及专注模式恢复；
- 标签区域动态高度与滚动阈值；
- 36×36 点击目标；
- 导出预览和用量空状态的浅色、深色主题；
- 设置窗口紧凑布局；
- 已读状态不改变字重且保留无障碍说明。
